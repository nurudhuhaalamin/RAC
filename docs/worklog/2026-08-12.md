### [T-101] Scaffold Astro 7

**Tujuan:** Menyiapkan kerangka aplikasi dari nol sesuai PLAN Bab 4 dan Bab 5, tanpa membuat
halaman atau komponen apa pun.

**Yang dikerjakan:**
- Astro 7.2.1 + adapter Cloudflare 14 + React 19 + Tailwind v4 (CSS-first) + Drizzle + Zod
- TS strict dengan `noUncheckedIndexedAccess` dan `verbatimModuleSyntax`
- ESLint flat config, Prettier, Vitest, Playwright (chromium + mobile)
- Struktur folder PLAN Bab 5 lengkap, `wrangler.toml` dengan id placeholder
- `scripts/db-migrate-local.mjs` — migration lokal saja, idempoten lewat tabel `__migrations`
- Hook `PostToolUse` (lint:staged) dipasang; sengaja ditunda di T-102 karena toolingnya belum ada

**File berubah:**
- `package.json` — **di-merge**, `check:content` dan `check:worklog` terverifikasi selamat
- `astro.config.mjs`, `tsconfig.json`, `wrangler.toml`, `drizzle.config.ts`
- `eslint.config.js`, `.prettierrc.json`, `.prettierignore`, `vitest.config.ts`, `playwright.config.ts`
- `src/env.d.ts`, `src/styles/global.css`, `src/styles/theme.css` (sementara), `src/pages/index.astro`
- `.claude/settings.json` — hook PostToolUse

**Keputusan teknis:**
- `output: 'server'` dipilih karena halaman publik dirender dari D1 lalu di-cache di KV (ADR-002),
  bukan karena isinya dinamis per permintaan.
- `main` dan `[assets]` **tidak** diset di `wrangler.toml`. Plugin Vite membaca config saat build
  dan gagal mencari `dist/_worker.js` yang belum ada — adapter yang menentukan entry.
- Aturan ESLint `consistent-type-imports` dibuang: butuh info tipe yang tidak diteruskan
  `astro-eslint-parser`, dan `verbatimModuleSyntax` sudah menegakkan hal sama saat kompilasi.

**Verifikasi:**
- `pnpm build` → sukses
- `pnpm typecheck` → **0 errors, 0 warnings, 0 hints**
- `pnpm lint` → bersih (ESLint + Prettier)
- `pnpm check:content` → LULUS, 23 file dipindai, 0 pelanggaran
- `better-sqlite3` native binding diuji langsung: insert + select berhasil
- `wrangler --version` → 4.122.0

**Masalah / catatan:**
- **Saya menebak versi `@cloudflare/workers-types@^4`; versi itu tidak ada** (terbaru v5). Install

  ADR-001. Diperbaiki setelah memverifikasi dengan `npm view`.

  better-sqlite3, esbuild, workerd, sharp — tanpa ini `wrangler dev` dan SQLite lokal tidak jalan.
- `wrangler.toml` memakai **id placeholder**. Situs belum bisa deploy sampai pemilik proyek
  mengisi id D1/KV/R2 asli.
